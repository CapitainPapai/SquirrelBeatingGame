# Squirrel Beating Game 🌳🔨

Уютная браузерная аркада в лесной эстетике: бей молотком по норам, лови бурундуков, собирай монеты
и прокачивай поляну. Полностью статический PWA-проект — без сборки, без зависимостей, без бэкенда.

**Играть локально:** запусти локальный сервер (по `file://` ES-модули не загрузятся):

```bash
python3 -m http.server 8080
# затем http://localhost:8080
```

## Что внутри

**Геймплей**

- 9 нор (3 × 3) на старте, бурундуки вылезают сами и прячутся через несколько секунд.
- Удар молотком: клик мышью, тап на телефоне или клавиши `1`–`9` / `Space` на клавиатуре.
- Монеты за попадание, бонус за быструю реакцию, серия без промахов, критические удары.
- Откат удара, размер поля (3 × 3 → 5 × 5), авто-молоток, сундуки и золотые жёлуди на поляне.
- Режимы: ярость, ускорение, прозрение, заморозка, лесной праздник.
- Прогресс сохраняется в `localStorage`, «Сторож леса» приносит офлайн-доход.

**30 видов бурундуков** с редкостями от «обычного» до «мифического», уникальными палитрами,
декором (очки, шарф, корона, гало, нимб, радуга…) и эффектами:

| Редкость | Примеры |
| --- | --- |
| Обычные | Рыжик, Серяк, Бурый Тимка, Пончик, Соня, Полосатик |
| Необычные | Барсик, Ушастик, Учёный Грызун, Садовник, Модник, Поэт |
| Редкие | Золотой, Красный Злой (ярость), Ниндзя, Волшебник, Часовщик, Банкир, Ледяной |
| Эпические | Изумрудный, Лунный, Огненный, Гром, Тень |
| Легендарные | Кристальный, Радужный, Король Дуба, Небесный |
| Мифические | Космический, Дух Леса |

**40 навыков прокачки** в 5 категориях: заработок, молоток, бурундуки, авто-молоток, особые.

**Музыка и звук** (всё синтезируется в реальном времени через Web Audio API, никаких mp3):

- 10 разных композиций (калимба, маримба, флейта, роудс, гитара, музыкальная шкатулка, эмбиент…).
  Меняются сами, любую можно выбрать в плейлисте: `Настройки → Плейлист леса`.
- Живой эмбиент леса: ветер, птицы, шелест листвы, сверчки, скрип дерева.
- Реалистичные SFX: деревянный удар, звон монет, покупка, клад, ярость, заморозка.

**Интерфейс**

- Три вкладки: Поляна, Энциклопедия (с прогрессом открытия видов), Магазин.
- Адаптив под телефон и десктоп, крупные зоны нажатия, поддержка safe-area (iPhone).
- Настройки громкости музыки / звуков / эмбиента, вибрация, сброс прогресса.
- Аккуратные анимации, «дышащий» лесной фон, молоток-курсор, эффекты монет и искр.

## Управление

| Действие | Телефон | Компьютер |
| --- | --- | --- |
| Удар | тап по норе | клик / `1`–`9` / `Space` |
| Вкладки | нижняя панель | нижняя панель |
| Музыка | чип с треком | чип с треком / Настройки |

## Звук на телефоне

Музыка синтезируется в `AudioContext` на лету, поэтому мобильные браузеры
считают её «подозрительной» и держат контекст на паузе. В коде это учтено:

- контекст создаётся и **возобновляется** прямо в обработчике тапа;
- любой тап/клик и возврат в приложение будят звук (`audio.wake()`);
- при сворачивании контекст **усыпляется** (`audio.sleep()`), а сетка тактов
  сбрасывается — поэтому после возврата нет «догоняющих» тактов и треска;
- планировщик смотрит вперёд на 1 с и не пытается доиграть пропущенное.

Если звука всё равно нет:

| Симптом | Причина | Что делать |
| --- | --- | --- |
| Тишина в установленном приложении (iPhone) | включён переключатель «Без звука» на торце — iOS глушит Web Audio | выключить переключатель, тапнуть по экрану |
| Тишина после звонка/наушников | iOS «прервал» аудиосессию | тапнуть по экрану — контекст разбудится |
| Тишина только в PWA, в браузере есть | кеш старой версии | закрыть приложение полностью и открыть снова (кеш `sbg-v5`) |
| Треск/разрывы | телефон в режиме энергосбережения или фоновые приложения | закрыть лишние приложения, отключить энергосбережение |

## Публикация в интернете

Игра — статический сайт: нужен любой бесплатный хостинг статики.
Проверенный и самый простой вариант — **GitHub Pages** (репозиторий публичный).

### GitHub Pages (бесплатно, из этого же репозитория)

1. Открой репозиторий → **Settings** → **Pages**.
2. **Build and deployment → Source**: `Deploy from a branch`.
3. **Branch**: `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты игра доступна по адресу
   `https://<твой-логин>.github.io/SquirrelBeatingGame/`.

Файл `.nojekyll` в корне уже есть — без него Pages пытается обрабатывать сайт
через Jekyll и может выкидывать часть файлов. Service worker работает, PWA
устанавливается на телефон («На главный экран» / «Установить приложение»).

Отдельного билда нет: Pages раздаёт содержимое ветки как есть.

### Альтернативы

- **Cloudflare Pages** — бесплатно, без лимитов трафика: «Upload assets» → перетащить папку.
- **Любой статический хостинг** (Vercel, Surge, свой сервер) — достаточно залить
  корень проекта. Требование одно: игра должна открываться по `http(s)://`,
  а не по `file://`, иначе ES-модули не загрузятся.

### Локально

```bash
python3 -m http.server 8080     # или: npx serve .
```
→ `http://localhost:8080`.

## Нативная версия (Tauri v2)

Кроме веба игру можно собрать как обычное приложение — `.exe`/`.msi` для Windows,
`.dmg` для macOS, `.deb`/`.AppImage` для Linux, `.apk`/`.aab` для Android и `.ipa` для iOS.
Веб-версия при этом остаётся главной: `tauri/` — отдельная папка («ветка») проекта,
она ничего не меняет в корне и в веб-деплое.

```bash
cd tauri
npm install          # один раз
npm run dev          # запуск приложения в режиме разработки
npm run build        # сборка установщика для текущей ОС
npx tauri info       # проверить, что установлены Rust и зависимости
```

Мобильные цели:

```bash
npm run android:init && npm run android:dev     # нужен Android Studio + NDK
npm run ios:init     && npm run ios:dev         # нужен macOS + Xcode
```

Что важно знать:

- **Прогресс** хранится в файле `save.json` в приватной папке приложения
  (а не только в `localStorage`, который WebView может вычистить). Сейв из браузера
  переносится автоматически при первом запуске, вручную — кнопками
  «Экспорт прогресса» / «Импорт прогресса» в настройках.
- **Сборка веб-части** автоматическая: `tauri/scripts/prepare-web.mjs` копирует
  `index.html`, `css`, `js`, `icons` в `tauri/web` (service worker в приложении не нужен).
- **Иконки** всех размеров уже лежат в `tauri/src-tauri/icons/`, свои можно собрать
  командой `npm run icons` из `src-tauri/icons/source-icon.png`.
- **Готовый CI уже включён** — `.github/workflows/tauri-build.yml` (копия в `tauri/ci/`):
  GitHub → вкладка **Actions** → **Tauri build** → **Run workflow** собирает `.exe/.msi`,
  `.dmg`, `.deb/.AppImage` и `.apk/.aab` прямо в облаке, без установки SDK на свой компьютер.
  Тег вида `v1.0.0` дополнительно создаёт черновик релиза с этими файлами.
- Публикация: Microsoft Store, Google Play ($25, `.aab`), App Store ($99/год, нужен Mac).
  Подробная инструкция по зависимостям, ключам подписи и частым ошибкам — в
  [`tauri/README.md`](tauri/README.md).

Полный гайд: **[tauri/README.md](tauri/README.md)**.
