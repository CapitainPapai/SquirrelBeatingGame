# Squirrel Beating Game 🌳🔨

Уютная браузерная аркада в лесной эстетике: бей молотком по норам, лови бурундуков, собирай монеты
и прокачивай поляну. Полностью статический PWA-проект — без сборки, без зависимостей, без бэкенда.

**Играть локально:** открой `index.html` (лучше через локальный сервер — так работает PWA-кеш):

```bash
python3 -m http.server 8080
# затем http://localhost:8080
```

## Что внутри

**Геймплей**

- 9 нор (3 × 3) на старте, бурундуки вылезают сами и прячутся через несколько секунд.
- Удар молотком: клик мышью, тап на телефоне или клавиши `1`–`9` / `Space` на клавиатуре.
- Монеты за попадание, бонус за быструю реакцию, серия без промахов, критические удары.
- Откат удара, размер поля (3 × 3 → 5 × 5), авто-молоток, сундуки и золотые жёлуди на поляне.
- Режимы: ярость, ускорение, прозрение, заморозка, лесной праздник.
- Прогресс сохраняется в `localStorage`, «Сторож леса» приносит офлайн-доход.

**30 видов бурундуков** с редкостями от «обычного» до «мифического», уникальными палитрами,
декором (очки, шарф, корона, гало, нимб, радуга…) и эффектами:

| Редкость | Примеры |
| --- | --- |
| Обычные | Рыжик, Серяк, Бурый Тимка, Пончик, Соня, Полосатик |
| Необычные | Барсик, Ушастик, Учёный Грызун, Садовник, Модник, Поэт |
| Редкие | Золотой, Красный Злой (ярость), Ниндзя, Волшебник, Часовщик, Банкир, Ледяной |
| Эпические | Изумрудный, Лунный, Огненный, Гром, Тень |
| Легендарные | Кристальный, Радужный, Король Дуба, Небесный |
| Мифические | Космический, Дух Леса |

**40 навыков прокачки** в 5 категориях: заработок, молоток, бурундуки, авто-молоток, особые.

**Музыка и звук** (всё синтезируется в реальном времени через Web Audio API, никаких mp3):

- 10 разных композиций (калимба, маримба, флейта, роудс, гитара, музыкальная шкатулка, эмбиент…).
  Меняются сами, любую можно выбрать в плейлисте: `Настройки → Плейлист леса`.
- Живой эмбиент леса: ветер, птицы, шелест листвы, сверчки, скрип дерева.
- Реалистичные SFX: деревянный удар, звон монет, покупка, клад, ярость, заморозка.

**Интерфейс**

- Три вкладки: Поляна, Энциклопедия (с прогрессом открытия видов), Магазин.
- Адаптив под телефон и десктоп, крупные зоны нажатия, поддержка safe-area (iPhone).
- Настройки громкости музыки / звуков / эмбиента, вибрация, сброс прогресса.
- Аккуратные анимации, «дышащий» лесной фон, молоток-курсор, эффекты монет и искр.

## Публикация на Netlify Drop

Проект готов к загрузке «как есть»:

1. Открой [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащи **папку проекта** (ту, где лежит `index.html`) в окно браузера.
3. Netlify выдаст ссылку — игра сразу работает, PWA можно установить на телефон
   («На главный экран» / «Установить приложение»).

`netlify.toml` уже содержит нужные заголовки, а `sw.js` кеширует игру для офлайна.
Деплой вручную через CLI: `npx netlify-cli deploy --prod --dir .`

### Плашка «Powered by Netlify»

Netlify с 19.08.2026 сам добавляет на бесплатные проекты плашку в правом нижнем углу —
в коде игры её нет. На телефоне она перекрывает нижнюю панель вкладок. Убирается бесплатно:

1. Открой проект на [app.netlify.com](https://app.netlify.com).
2. **Project configuration → General → Powered by Netlify badge** → снять галочку → сохранить.
3. Редеплой не нужен — плашка исчезает со следующего запроса.

Страховка от плашки уже встроена: `js/netlify-badge.js` + правила в `css/style.css`
удаляют её элементы (`#nl-badge-frame`, `.nl-badge*` и iframe HUD-скрипта), если переключатель
ещё недоступен. Если плашка не нужна в проекте совсем — удали один `<script>` из `index.html`
и блок `/* Плашка «Powered by Netlify» */` из `css/style.css`.

**Если хочется хостинг без плашки вообще:** Cloudflare Pages (бесплатно, без бейджа) —
создать проект → «Upload assets» → перетащить эту же папку. GitHub Pages потребует
публичный репозиторий (или GitHub Pro для приватного).

## Структура

```
index.html                разметка экранов, HUD, вкладки
manifest.webmanifest      PWA-манифест (иконки, standalone)
sw.js                     service worker: офлайн-кеш
netlify.toml              заголовки и publish-настройки
css/style.css             визуальный стиль, анимации, адаптив
js/main.js                точка входа: связка состояния, игры, UI, звука, PWA
js/game.js                игровой движок: норы, спавн, удары, буффы, эффекты
js/ui.js                  HUD, магазин, энциклопедия, модалки, настройки
js/state.js               сохранение (localStorage), покупки, офлайн-доход
js/audio.js               Web Audio: 10 треков, эмбиент, SFX
js/art.js                 процедурный SVG-арт бурундуков, молотка, жёлудя, сундука
js/netlify-badge.js       удаляет плашку «Powered by Netlify», если она появилась
js/data/squirrels.js      30 видов: редкости, палитры, эффекты, шансы
js/data/skills.js         40 навыков, стоимости, расчёт статов, размеры поля
js/utils.js               форматирование чисел и времени
icons/                    иконки PWA (png/svg)
```

## Скрипты-помощники (необязательно)

Проекту не нужен `npm install`, но удобно поднять сервер:

```bash
npx serve .          # или python3 -m http.server 8080
npx netlify-cli deploy --prod --dir .
```

Сделано с любовью к лесу: весь арт — процедурный SVG, вся музыка — синтез в браузере.
